# Meu Pluggy for single-owner Open Finance

The dashboard will replace Belvo with Pluggy's Meu Pluggy personal-use route because it provides up to five active Open Finance Connections and daily data updates without an expiry for one person's non-commercial use. The application will enforce exactly one Financial Owner, obtain bank consent through Meu Pluggy, treat provider updates as non-real-time, and preserve local data independently of the provider connection lifecycle.
